- 使用者確認後，再寫入 `local_tm_certification` 外掛。

### P9 現場點名＋簽到 QR（已實作 · 待測 · 預覽仍可供對照）

**講師**

- 名單表「現場點名」欄：到課／遲到／未到（預設未點名）；可手動改。
- 入口「本場簽到 QR」：顯示／下載／複製連結／重新產生（作廢舊碼）。

**學生（方案 A）**

- 掃 QR → **須先登入 Moodle** → 自動對本場名冊 → 一鍵確認（不選名字）。
- 時間規則（系統判定）：
  - 開場前 → **到課**
  - 開場後～場次結束前 → **遲到**
  - 場次結束後 → **自簽關閉**
- 無最早開放時間；QR 由講師在場次中產生。
- 已簽到再掃：只顯示結果，不覆寫時間；狀態有誤由講師在名單改。

**版本：** 0.11.0（2026073051）

### P10 代理下載（已定案 · 預覽中）

- 學員自助下載仍交 Moodle；外掛不做通過門禁。
- 「有證書」＝ Moodle customcert **已核發或可領取**。
- 場次名單：通過狀態＋單一下載＋**本場**證書批次。
- 全站搜尋批次：檢定儀表板（manage／approve）獨立按鈕 → `cert_batch_site.php`。
