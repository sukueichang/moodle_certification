# UI 預覽維護

**唯一入口：** [`ui_preview.html`](ui_preview.html)

- 新 UI 提案請**追加**到此檔（上方功能區，或區內子分頁），不要再新增獨立 `*_preview.html`。
- 相關畫面需可在同一檔內點按切換。
- 使用者確認後，再寫入 `local_tm_certification` 外掛。

## 目前提案焦點

| 功能區 | 說明 |
| :--- | :--- |
| **學員名單（P10）** | 通過狀態＋列上單一下載；證書批次下載（本場通過者／搜尋全站）＋摘要＋zip |
| 首頁區塊 | Moodle 網站首頁／我的首頁注入卡（v4） |
| 儀表板／成績／證書 | 既有預覽 |

### P10 代理下載（已定案 · 預覽中）

- 學員自助下載仍交 Moodle；外掛不做通過門禁。
- 「有證書」＝ Moodle customcert **已核發或可領取**。
- 場次名單：通過狀態＋單一下載＋**本場**證書批次。
- 全站搜尋批次：檢定儀表板（manage／approve）獨立按鈕 → `cert_batch_site.php`。
