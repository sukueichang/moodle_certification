# UI 預覽維護

**唯一入口：** [`ui_preview.html`](ui_preview.html)

- 新 UI 提案請**追加**到此檔（上方功能區，或區內子分頁），不要再新增獨立 `*_preview.html`。
- 相關畫面需可在同一檔內點按切換。
- 使用者確認後，再寫入 `local_tm_certification` 外掛。
